🛡️ Administrator Portal URL Path (URL Cloaking)

Customize the URL path used to access this administration panel (default: /admin). Concealing the admin URL mitigates opportunistic attack scans, automated bot probes, and targeted brute-force attempts.

Must start with / and contain only alphanumeric characters, hyphens, and underscores. Cannot conflict with reserved system paths (e.g. /, /access, /static, /health, /setup).
⚠️ Important Notice:
  • Changing the admin path takes effect immediately. The previous path will return 404 Not Found.
  • You will be redirected immediately to the new path. Remember to update your browser bookmarks.
  • Forgotten Path Recovery: If you ever forget your custom path, restart Funnel or inspect the service logs (e.g. journalctl -u funnel.service) to view the active admin URL.
